# 财报日历

打开就能看到自己持仓、观察的公司和美股科技龙头下一次什么时候发财报，以及上市、定价这类重要事件，全部按北京时间显示，带实时倒计时。

网页地址：https://jaqennn.github.io/earnings-calendar/

## 它是怎么自动更新的

- 每天北京时间早上 7 点左右，GitHub Actions 自动运行 `fetch.py`，从 Yahoo Finance 查各公司的财报日期，生成 `data.json`
- 新数据存回仓库，并自动发布到 GitHub Pages
- 网页打开时读取 `data.json`，倒计时按当前时间实时计算
- 不需要任何 API key、账号或密码，也不需要自己的电脑开着

## 怎么改关注的公司

编辑 `fetch.py` 里的 `WATCHLIST`，按「代码, 中文名」的格式加减即可。美股直接写代码（如 `AAPL`），港股加 `.HK`（如 `0700.HK`）。改完提交后会自动重新发布。

## 怎么加财报以外的事件（上市、定价、发布会等）

编辑 `events.json`，在 `events` 里照着现有的格式加一条。网页会把它和财报放在一起按日期排，也可以点「事件」单独看。

| 字段 | 必填 | 作用 |
| --- | --- | --- |
| `id` | 是 | 随便起一个不重复的英文名 |
| `title` | 是 | 显示的标题，如「Anthropic 上市首日」 |
| `utc` | 是 | 事件时间（UTC，北京时间减 8 小时），用来排序和倒计时 |
| `symbol` | 否 | 股票代码 |
| `tag` | 否 | 小标签，如「IPO」「发布会」 |
| `time_label` | 否 | 时间那一栏改成自己写的字，如「约22:30」「当周」 |
| `fuzzy` | 否 | `true` 表示具体日子没定，不参与顶部倒计时 |
| `confirmed` | 否 | `true` 表示官方已确认，否则显示「预估」 |
| `summary` | 否 | 标题下面的一行说明 |
| `details` | 否 | 点「详情」展开的几行补充 |
| `link` | 否 | 相关链接 |
| `until` | 否 | 什么时候从列表消失（UTC），默认事件时间后 12 小时 |

改完提交后网页自动重新发布，不用等每天的定时更新。

## 想马上更新一次

仓库页面 → Actions → 每日更新财报日历 → Run workflow。

## 说明

- 标「预估」的是公司还没正式公布、由数据源按往年规律估算的日期，可能会变
- 「时段未定」表示只知道日期；美股大多盘后发布，对应北京时间次日早上
- 美国夏令时切换已自动换算
- 数据仅供参考，以公司官方公告为准

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页本身 |
| `fetch.py` | 查询财报日期的脚本 |
| `data.json` | 脚本生成的财报数据 |
| `events.json` | 手动维护的非财报事件 |
| `.github/workflows/update.yml` | 每天自动运行的设置 |
